# Himesh Sharma Software Developer Portfolio

Static professional portfolio website for Himesh Sharma.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive visual design
- `script.js` - project card data and links
- `redirect.html` - direct routing page for GitHub, repositories, LinkedIn, and email

## Update Projects

When public GitHub repositories are ready, edit the `projects` array in `script.js` and replace the starter cards with direct repository links.
